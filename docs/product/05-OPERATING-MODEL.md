# CB-CAP — Operating model

## Decision rights

| Decision | Who |
|---|---|
| Change locked copy | Product owner |
| Accept a Decision Record | County owner only |
| Add Local Evidence | County owner or designee |
| Seed a new county | Tech Inc. facilitator + owner |
| Publish Public Preview | Foundation |
| Ship engineering | Repo maintainers against the PRD |

## Cadence

Source refresh when a public release is dated. No silent overwrite of accepted records.

## Data

Aggregate, deidentified, public or owner-provided. No PHI in v1. Citation locator required on Local Evidence.

## Allowed metrics

Time to first Decision Record draft. Share of dimensions still Not available. Owner can run the 20-minute script unassisted.

Not allowed: ZIP ranks, predicted cases, coverage lifted unless sourced outside CB-CAP.
