# Data request — week 1

Ask for public files first. Do not scrape behind a login without their written source.

## Public inventory (facilitator pre-loads)

| Layer | Ask | If absent |
|---|---|---|
| Place outlines | Census ZCTA vintage they accept | Label vintage; do not invent community names |
| Care sites | State profiles / CMS POS class | Seeded subset only; stamp “not inventory” |
| Affordability / chronic | CDC PLACES county or ZCTA as published | Keep county grain; do not downscale |
| Social priorities | Current CHA / CHIP | Leave Social as Planned source |
| Digital access | FCC / state broadband if they cite it | Not available — not zero |
| Trust | Only if they have a published measure | Not available |
| Workforce | HRSA / state shortage files they cite | Planning View if inferred |

## Local Evidence intake (week 4)

Each item needs: identity, date, scope, citation locator, mark.  
If any field is missing, mark stays Planned source or Not available.

## Never

Convert a missing cell to 0.  
Blend twelve dimensions into one index.  
Label a ZIP as a people-group.
