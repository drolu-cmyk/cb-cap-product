# Contributing

This is a private-product public repo. Changes must keep locked copy and the PRD acceptance list.

1. Read `docs/product/00-LOCKED-COPY.md` before writing UI strings.
2. Do not add a composite score, rank, forecast of individual health, or allocate control.
3. Do not treat Lewis County as a client in README badges or marketing copy.
4. Evidence objects need source, date, geography, denominator, missingness, limitations, mark.
5. Missing stays missing.

Open a pull request against `main`. Reference the PRD section you are implementing.
